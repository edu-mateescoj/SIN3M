# Mémento - commandes par ordre alphabétique

- [[02_COMMANDES/apt|apt]] : gestion des paquets logiciels.
- [[02_COMMANDES/cat|cat]] : afficher le contenu d'un fichier.
- [[02_COMMANDES/cd|cd]] : changer de dossier.
- [[02_COMMANDES/chmod|chmod]] : modifier les permissions.
- [[02_COMMANDES/chown|chown]] : modifier le propriétaire.
- [[02_COMMANDES/cp|cp]] : copier.
- [[02_COMMANDES/df|df]] : espace libre disque.
- [[02_COMMANDES/du|du]] : taille occupée.
- [[02_COMMANDES/free|free]] : mémoire RAM.
- [[02_COMMANDES/git|git]] : versionnage.
- [[02_COMMANDES/hostnamectl|hostnamectl]] : informations système.
- [[02_COMMANDES/ip|ip]] : adresses réseau.
- [[02_COMMANDES/journalctl|journalctl]] : journaux système.
- [[02_COMMANDES/ls|ls]] : lister les fichiers.
- [[02_COMMANDES/lsblk|lsblk]] : périphériques de stockage.
- [[02_COMMANDES/lscpu|lscpu]] : informations CPU.
- [[02_COMMANDES/lsusb|lsusb]] : périphériques USB.
- [[02_COMMANDES/mkdir|mkdir]] : créer un dossier.
- [[02_COMMANDES/nano|nano]] : éditer un fichier en terminal.
- [[02_COMMANDES/ping|ping]] : tester une connexion.
- [[02_COMMANDES/pwd|pwd]] : afficher le dossier courant.
- [[02_COMMANDES/reboot|reboot]] : redémarrer.
- [[02_COMMANDES/rm|rm]] : supprimer.
- [[02_COMMANDES/rmdir|rmdir]] : supprimer un dossier vide.
- [[02_COMMANDES/scp|scp]] : copier via SSH.
- [[02_COMMANDES/ssh|ssh]] : se connecter à distance.
- [[02_COMMANDES/ssh-copy-id|ssh-copy-id]] : installer une clé publique.
- [[02_COMMANDES/ssh-keygen|ssh-keygen]] : créer une paire de clés SSH.
- [[02_COMMANDES/sudo|sudo]] : exécuter avec droits administrateur.
- [[02_COMMANDES/systemctl|systemctl]] : gérer les services.
- [[02_COMMANDES/tar|tar]] : archiver / extraire.
- [[02_COMMANDES/uname|uname]] : informations noyau.
- [[02_COMMANDES/vcgencmd|vcgencmd]] : diagnostic Raspberry Pi.
- [[02_COMMANDES/whoami|whoami]] : utilisateur courant.

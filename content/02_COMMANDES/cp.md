# cp

## Sens du nom

`cp` : **copy**.

## Rôle

Cette commande copie des fichiers ou dossiers.

## Syntaxe générale

```bash
cp [options] [arguments]
```

## Exemples du projet

```bash
cp source.txt copie.txt
cp -r dossier dossier-copie
```

## À retenir

- Lire attentivement la commande avant d'appuyer sur Entrée.
- Une option commence souvent par `-` ou `--`.
- Les commandes qui modifient le système demandent souvent [[sudo]].

## Erreurs fréquentes

- faute de frappe ;
- mauvais dossier courant ;
- droits insuffisants ;
- connexion réseau absente, si la commande dépend d'Internet.

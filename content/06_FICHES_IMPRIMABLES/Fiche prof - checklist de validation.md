# Fiche prof - checklist de validation

- [ ] Carte microSD fournie.
- [ ] Boot réussi.
- [ ] Écran école compatible.
- [ ] Clavier école utilisable.
- [ ] Souris école utilisable.
- [ ] Alimentation suffisante au démarrage.
- [ ] `vcgencmd get_throttled` vérifié.
- [ ] Ethernet fonctionnel.
- [ ] Internet fonctionnel.
- [ ] DNS fonctionnel.
- [ ] SSH activé.
- [ ] SSH local testé.
- [ ] Clé SSH créée.
- [ ] Git configuré.
- [ ] Dépôt GitHub cloné ou initialisé.

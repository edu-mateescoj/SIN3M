# Fiche élève - commandes essentielles

| Commande | Rôle |
|---|---|
| `pwd` | afficher le dossier courant |
| `ls` | lister les fichiers |
| `cd` | changer de dossier |
| `cat` | afficher un fichier |
| `ip -br addr` | afficher les adresses réseau |
| `ping -c 4 site` | tester une connexion |
| `sudo apt update` | mettre à jour la liste des paquets |
| `sudo apt full-upgrade -y` | installer les mises à jour |
| `sudo systemctl enable --now ssh` | activer SSH |
| `ssh utilisateur@adresse` | se connecter à distance |
| `git status` | voir l'état du dépôt Git |

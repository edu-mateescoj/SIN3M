# Glossaire rapide

## Termes informatiques généraux
- **vault Obsidian** : dossier de notes Markdown ouvert avec Obsidian.

- **CLI** : interface en ligne de commande.

- **SSH** : protocole permettant d'ouvrir une session distante sécurisée sur une machine.

- **clé publique / clé privée** : paire cryptographique utilisée pour s'authentifier sans mot de passe.

- **adresse IP** : identifiant numérique d’un appareil sur un réseau (wlan : WiFi, ethernet par cable). IPv4 est composée de 4 nombres de 0 à 255. Différents usages : 0.0.0.0 signifie "toutes les interfaces disponibles" (la machine écoute sur toutes ses adresses), 127.0.0.1 désigne la machine elle-même sans passer par le réseau, x.y.z.u peut désigner une adresse sur Internet

- **Numéro de port** : le numéro de port (0–65535) suit l'adresse IP pour identifier quel service/application reçoit le trafic — que ce soit en local (localhost:3000), en réseau local (192.168.x.x:8080) ou sur Internet (ex. port 443 pour HTTPS).

- **NAT** : mécanisme permettant à plusieurs machines privées de sortir sur Internet via une adresse publique.

## Termes spécifiques à l'outil de versionnage Git/GitHub

- **Git vs. GitHub** : **Git** est un outil de versionnage local, à installer sur la machine ; **GitHub** est une plateforme en ligne pour héberger, partager et collaborer sur des dépôts Git.
- **dépôt Git** : dossier versionné par Git.
- **commit** : photographie d'un état du projet.
- **push** : envoi des commits vers un dépôt distant.
- **pull** : récupération des commits depuis un dépôt distant.

### 01. Configuration SSH Raspberry

Matériel : raspberry + câble usb-a micro-usb (alimentation) + carte SD.

Un ou deux writerdeck complet dans la salle (celui de Julien G. par exemple) avec son écran. 
#### Durée : une journée complète.

1. Flashage de la carte SD modifiée pour simplifier l'installation
2. Installation de l’OS (DietPi ou Raspbian)
3. Accès SSH, configuration de base -raspiconfig (disposition de clavier Qwertz, wifi)
4. Installation du logiciel d’écriture :  wordgrinder, focuswriter (interface graphique), VSCode, etc. (choix possible avec un comparatif ?) → les élèves devront justifier leurs choix techniques
5. Solution de partage : syncthing (vérifier si ça tourne sur un RP0 2w) ou un simple partage réseau SAMBA.
6. Boot en mode kiosque sans curseur
7. Personnalisation de l’environnement d’écriture (couleur, typographie, marges, etc. à peaufiner sur les logiciels tournant sur un terminal) + raccourcis claviers.
#### Rendu : 
- un setup complet pour écrire, en justifiant les choix d’ergonomie.
#### Évaluation :
- la carte sd est glissée dans le rasperry connecté à un écran, vérifier que tout fonctionne (clavier reconnu + boot en mode kiosque + interface d’écriture et partage de fichier).
- Le Rpi sert les fichiers distants : vault obsidian. Objectif évaluable : les modifs distantes sont visibles

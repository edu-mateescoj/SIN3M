# 02 - Identifier sa carte et son système

## Commandes

```bash
cat /proc/device-tree/model
free -h
lscpu | head -20
uname -a
```

## Résultat attendu

L'élève doit pouvoir identifier :

- le modèle exact du Raspberry Pi ;
- la mémoire RAM disponible ;
- le processeur ;
- le noyau Linux utilisé.

# 00 - Vue d’ensemble du parcours

## Objectif

Comprendre le déroulement complet : démarrer un Raspberry Pi, vérifier le matériel, le réseau, les mises à jour, SSH, GitHub et le vault Obsidian.

## Étapes

1. Démarrage matériel.
2. Identification du modèle.
3. Vérification écran / clavier / souris / alimentation.
4. Vérification réseau.
5. Mise à jour du système.
6. Activation de SSH.
7. Création d'une clé SSH.
8. Configuration Git/GitHub.
9. Configuration du vault distant.
10. Diagnostic final.
